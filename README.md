# Catgame

Пиксельная игра про котов с разрушаемым миром: зомби-оборона, сражения, онлайн с друзьями.

## Скачать
Раздел **Releases** справа → последний выпуск → `Catgame-Setup-….exe`.
Запусти установщик — на рабочем столе появится ярлык «Catgame». Дальше игра обновляется сама.

Windows может предупредить «неизвестный издатель» — нажми «Подробнее» → «Выполнить в любом случае».
При первом запуске разреши игре доступ к сети (нужно для игры с друзьями).
